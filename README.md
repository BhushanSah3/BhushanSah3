## Selected projects

### [RepoMind](https://github.com/BhushanSah3/RepoMind) - multi-agent codebase analysis

A developer tool that helps users explore and reason about a codebase through specialized AI agents.

- Routes questions to Architect, Bug Hunter, and Code Reviewer agents using LangGraph.
- Combines AST-aware chunking, dependency graphs, ChromaDB vector search, BM25, reciprocal-rank fusion, and cross-encoder reranking.
- Includes adaptive retries and RAG Triad evaluation; the workflow is covered by 45 passing PyTest tests.

**Built with:** Python, LangGraph, LangChain, ChromaDB, BM25, Streamlit

### [VeriStream](https://github.com/BhushanSah3/Veristream) - multimodal content verification

A containerized platform for examining text, audio, URLs, and web content for potential misinformation.

- Uses Whisper transcription, SentenceTransformers, semantic retrieval, and claim-evidence comparison to flag questionable content.
- Packaged ML services with Docker and deployed them on Azure while collaborating in a four-person Agile team across 100+ commits.
- Evaluated transcript-level verification by tuning embedding-similarity thresholds across diverse claim-evidence pairs; results varied by the evaluation set and threshold.

**Built with:** Python, FastAPI, Whisper, Docker, Azure
